# Recallio – Flashcard Quiz App

**A clean, interactive, and engaging flashcard learning experience built with Flutter.**

Recallio is a flashcard quiz application developed as **Task 1 of the CodeAlpha App Development Internship**. It helps users organize study materials, review flashcards, and practice through quiz mode.

## ✨ Features

- 📚 **Flashcard Learning:** View questions and reveal their answers.
- 🔄 **Study Navigation:** Move between flashcards using Previous and Next controls.
- ✏️ **Card Management:** Add, edit, and delete flashcards.
- 🧠 **Quiz Mode:** Practice knowledge through interactive quizzes.
- 📊 **Study Statistics:** Track learning activity and progress.
- 🎨 **Clean UI:** A simple and user-friendly interface.
- 🗂️ **Categories:** Organize flashcards for different study topics.

## 🛠️ Technologies Used

- Flutter
- Dart

1. Clone this repository.
2. Open the project folder in VS Code.
3. Install dependencies:

   `flutter pub get`

4. Run the application:

   `flutter run`
